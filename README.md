# Bill Splitter & Tip Calculator

A React JS mini project built with Vite.

Enter the total bill, select a tip percentage, and the number of friends — 
the app instantly calculates how much each person needs to pay.

## Features
- Real-time bill splitting calculation
- Tip percentage buttons (5%, 10%, 15%, 20%, 25%) + custom tip
- Friends counter
- Shows per person bill, tip, and total

## Tech Used
- React JS
- Vite
- CSS

## Project Structure
- Data stored in `src/data/billData.json`
- Separate components for Header, BillForm, and ResultCard
